# Original matchday ambient scores

Five original 16-second instrumental loops, generated locally for this portfolio.
No club anthem, broadcast audio, crowd recording, or third-party composition is used.

Source: `work/matchday-score/generate.py` (NumPy and FFmpeg).
Mono MP3, 24 kHz, 64 kbps. Pad chords, soft bell notes, and a quiet synthetic air layer.
Audio is loaded only after an explicit play action. Playback pauses when the tab is hidden.
The individual club names label portfolio themes, not official or endorsed club recordings.
