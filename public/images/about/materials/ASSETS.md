# Material sources

Local 1K textures from Poly Haven, licensed CC0:

- Concrete Floor 02: https://polyhaven.com/a/concrete_floor_02
- Wood Floor: https://polyhaven.com/a/wood_floor
- License: https://polyhaven.com/license

Diffuse, OpenGL normal and roughness maps. No executable third-party source used.

## Journal realism pass — 6 November 2026

The `journal/` directory contains 512px WebP derivatives of these 1K CC0 texture sets. Colour maps use quality85, normal and roughness maps use quality92. No external texture requests occur while viewing the site.

- `rock-*`: [Rock Boulder Cracked](https://polyhaven.com/a/rock_boulder_cracked), by Dario Barresi and Dimitrios Savva.
- `ground-*`: [Rocky Terrain02](https://polyhaven.com/a/rocky_terrain_02), by Amal Kumar.
- `concrete-*`: derivatives of the existing [Concrete Floor02](https://polyhaven.com/a/concrete_floor_02) maps above. Colour remapped toward neutral weathered concrete for the miniature scale; source originals unchanged.

All three sets contain colour, OpenGL normal and roughness maps. [Poly Haven CC0 licence](https://polyhaven.com/license).
